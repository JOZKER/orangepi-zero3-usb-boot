# 脱敏与公开范围

公开项目从空目录建立，仅加入启动相关源码、示例和重新撰写的文档，没有导入原工作目录的 Git 历史。

移除或不分发的内容包括：账户、密码及其哈希、API Key、QQ 账号及群名单、校园网账号、认证服务器地址、热点密码、应用访问令牌、SSH 密钥、设备序列号、MAC、真实文件系统 UUID、boot ID、Windows 用户目录、原始终端日志、完整 SPI 镜像，以及任何正在运行的系统镜像。

保留 Ubuntu 输入文件名、软件版本、公开固件的 SHA256、板型、容量范围和技术步骤。这些用于核对兼容性，不包含原设备的登录配置。Git 提交使用 GitHub noreply 邮箱，不公开私人邮箱。

`.gitignore` 排除构建产物、备份和常见敏感文件；`tools/check_public_tree.py` 在本地及 CI 中扫描受版本控制的文件。首次发布还额外在仓库外使用私有现场数据核对候选文件，检查已知凭据是否残留；不会将这些私有值放入扫描器源码或测试用例。

任何运行时生成的 `plan.json`、原 SPI 备份、主机配置和日志都属于本地资料，建议放在已忽略的 `local/` 或 `backups/` 目录。公开验证报告仅包含技术状态，不能复制原始设备配置来充当“示例”。
